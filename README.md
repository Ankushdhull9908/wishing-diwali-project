# Happy Diwali, Juju 💛

A React + Vite surprise: tap the matchstick, watch the rocket climb, and the sky explodes into fireworks and a message.

## Run locally
```
npm install
npm run dev
```

## Build
```
npm run build
```
The finished site is in `dist/`.

## Deploy (free)
- **Netlify:** drag the `dist/` folder onto https://app.netlify.com/drop
- **Vercel:** push to GitHub, import the repo, keep the defaults.
- **GitHub Pages:** push `dist/` to a `gh-pages` branch (the config already uses relative paths).

## Edit the message
Open `src/App.jsx` and search for `Happyyy Diwaliii`, `My Jujuuuu Babyyyyy` and `I love you so much`.
